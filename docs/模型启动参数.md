### qwen25-1.5b

## 启动接口

```text
POST /api/v1/models/{modelId}/run
```

请求需携带外部 API 的 Bearer Token。`{modelId}` 是模型的唯一标识；请求体中的
`id` 可省略，提供时必须与 URL 中的值完全一致。接口会创建 VLLM 模型 App，并返回：

```json
{
  "status": 200,
  "data": {
    "name": "mod-epc8fd1hzpadso7k6lw20w3312",
    "code": "deepseek4.0",
    "profile": "VLLM",
    "url": "http://..."
  }
}
```

调用方给出的 `param` 按行拆分为 VLLM 参数；服务会自动补充模型文件路径、监听地址
`0.0.0.0` 和端口（默认 `8000`）。

--served-model-name
qwen25-15b
--max-num-seqs
16
--max-model-len
8192
--enforce-eager
